## Page structure (top to bottom)

1. **Header** (68px, border-bottom, not sticky): logo "kopecjan" with a 10px accent square; anchor nav (Ask AI, Projects, Skills, Experience, Contact) hidden under 760px; language switch (two segmented buttons CZ / EN, active = accent-soft fill + accent text); theme toggle (sun / moon icon, 36px); hamburger on mobile opening a simple full-width menu with the five anchors.
2. **Hero**: two columns (1fr + 300px), photo right 280×280, radius 24, border; on mobile one column, photo first at 280×280 left-aligned. Eyebrow, H1, lead paragraph (max-width 600px), location line with pin icon, CTA row: primary "Ask my AI about me" (anchor to #ask), secondary "Download CV" (locale-specific PDF), two 46px icon links (LinkedIn, e-mail). On mobile the CTA row stacks full width.
3. **Ask about Jan** (`id="ask"`, surface background with top and bottom borders): heading + subtitle (max-width 680px); grid 1.45fr + 1fr: left the Chat component plus the note "Answers are generated by AI from Jan's CV and project notes."; right the "How it works" card: 5 numbered steps with a vertical connector (circle 28px, accent-soft fill, last one solid accent with white text), then a row of chips (Next.js, Embeddings, Vector search, Claude API). One column under 760px, chat first.
4. **Projects**: 3 cards (Flatter.cz / SaaS badge, TAO Real Estate / Beta badge, Ask about Jan / RAG badge). Card: title + badge row, one-sentence description (muted, flex-grow so links align), tag chips, link with arrow icon. Copy and tags are in `messages/*.json` under `projects`.
5. **Skills** (surface background): 3-column grid of 9 group cards, each a group label in accent + tag chips. Order and content exactly as in `messages/*.json` `skills`. No bars, no percentages.
6. **Experience**: vertical timeline (2px line, 16px dots, first dot accent), four `<details>` items; the first is open by default. Summary row: title + organisation left, period + chevron right. Content: bullet list. Under the timeline a 2-column grid: Education card and Languages card.
7. **Contact** (surface background): centered card (radius 20, padding 48/40), heading, one sentence, buttons: primary e-mail, secondary LinkedIn, secondary Download CV.
8. **Footer**: left "© 2026 Jan Kopecký · IČO [placeholder]", right links kopecjan.cz, LinkedIn, e-mail; stacks on mobile.

Breakpoint: a single one at 760px (`md`). Below it: nav hidden, hero / ask / cards / skills / education grids become one column, headings shrink as in the table, CTA rows stack, timeline left padding 28px.

## Chat component

Panel: `--card` background, 1px border, radius 16, min-height 560px, three zones.

- **Header**: 32px icon tile (sparkle, accent-soft), title "Jan's AI assistant", subtitle "Answers from Jan's CV and project notes", right a counter chip "n / 10 questions" (reads the remaining quota from the API response header `X-RateLimit-Remaining`).
- **Messages** (`--bg` background, padding 18, gap 14, `aria-live="polite"`): assistant bubbles left with a 26px "AI" tile, `--surface` fill, radius 4/14/14/14; user bubbles right, `--accent-bg` fill, white text, radius 14/4/14/14, max-width 80 to 88%.
- **Composer**: input 44px (radius 10, border `--border`, focus border `--accent` + 3px `--accent-soft` ring), send button 44×44 (`--chip` when input empty, `--accent-bg` when it has text), hint line under it "Press Enter to send. Answers may contain mistakes; the CV is the source of truth."

States (one reducer, `status` field):

| status | What is shown |
| --- | --- |
| `welcome` | welcome bubble + 4 suggested question chips (from `messages` `chat.chips`); clicking a chip submits it |
| `typing` | same as welcome, input focused and filled, send button active |
| `streaming` | user bubble, assistant bubble filling token by token with a blinking caret, status line with three pulsing dots "Writing the answer", input disabled, send button becomes a Stop button (aborts the fetch) |
| `answered` | full answer, under it "Sources" label + source chips (links: CV chip opens the PDF, others scroll to `#projects` or open the project link if present) |
| `fallback` | assistant bubble with the "I don't know that from Jan's documents..." text, buttons "Contact Jan" (mailto) and "Ask something else" (returns to welcome, keeps history) |
| `error` | red tile + red-bordered bubble "Something went wrong. ..." and a Retry button that resubmits the last question |
| `ratelimit` | yellow banner with clock icon, text from `messages` `chat.limit*`, input disabled with placeholder "Limit reached, try again later", send disabled |

History: keep the list of turns in state; a new question appends. Scroll the messages zone to the bottom on every update. Chips disappear after the first question.
